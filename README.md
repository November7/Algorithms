# Polski

Repozytorium zawiera zbiór interaktywnych symulacji znanych algorytmów. Przykłady są przygotowane jako strony HTML, CSS i JavaScript, które pozwalają obserwować działanie algorytmów krok po kroku. Znajdują się tu algorytmy sortowania, wyszukiwania, wyznaczania minimum i maksimum oraz przeszukiwania grafów (DFS i BFS).

[Algorytmy grafowe](graph.html) pozwalają losować grafy spójne, drzewa i grafy z dwiema składowymi, wybrać wierzchołek startowy oraz śledzić kolejkę BFS, stos DFS i drzewo przeszukiwania. Dostępne są animacja, pauza i wykonywanie pojedynczych kroków.

Testy symulacji grafowej można uruchomić poleceniem `node --test tests/graph.test.cjs` (Node.js 18 lub nowszy, bez dodatkowych pakietów).

README oraz symulacje w tym repozytorium są tworzone przy użyciu sztucznej inteligencji.

Lista dostępnych symulacji znajduje się na [GitHub Pages](https://november7.github.io/AlgorithmsLab/)

# English

This repository is a collection of interactive simulations of well-known algorithms. The examples are built as HTML, CSS, and JavaScript pages so you can observe how algorithms work, step by step. It includes sorting, searching, minimum and maximum selection, and graph traversal (DFS and BFS).

[Graph algorithms](graph.html) lets you generate connected graphs, trees, and graphs with two components, choose a starting vertex, and follow the BFS queue, DFS stack, and traversal tree. Animation, pause, and single-step controls are available.

Run the graph simulation tests with `node --test tests/graph.test.cjs` (Node.js 18 or later, no additional packages required).

This README and the simulations in this repository are created using artificial intelligence.

The list of available simulations is on the [GitHub Pages](https://november7.github.io/AlgorithmsLab/)
